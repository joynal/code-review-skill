# Review Checklist

A copyable record for a requested checklist. Mark unchecked areas as not reviewed or not applicable; a check means inspected, not proven defect-free.

- [ ] Target comparison and requirements identified.
- [ ] Repository instructions and supported versions checked.
- [ ] Changed behavior traced through callers and tests.
- [ ] Relevant language and topic references consulted.
- [ ] Candidate issues checked against existing protections.
- [ ] Concrete triggers, impacts, and locations verified.
- [ ] Focused checks recorded with their actual outcomes.
- [ ] Duplicate findings combined and severity justified.
- [ ] Coverage limits and unresolved questions disclosed.

Use [SKILL.md](../SKILL.md) for the workflow and severity definitions. Detailed technical checks live in its linked references.
